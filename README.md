💖使用教程 - PC端(此处以Edge作为演示)

在Edge的插件商店在下载安装油猴(篡改猴)Tampermonkey

访问 Script Installation | Tampermonkey

在Edge的管理插件页面中打开开发人员模式

在Edge的油猴插件管理界面中打开允许用户脚本

至此为止，PC端教程结束，你可以关闭没用的窗口，然后使用浏览器播放网课试试

请注意： 在 锁定进度条 功能关闭情况下调整进度条会影响课程的完成度

💖使用教程 – 手机端(以Edge作为演示)

在你的浏览器或手机应用商店中搜索并下载Edge

打开Edge关闭没有必要的弹窗，点击右下角的菜单按钮

点击弹出菜单中的扩展按钮

找到篡改猴一项，并点击右侧的获取按钮

点击需要启用开发人员模式才能使用此扩展,然后点击添加按钮

等待下载完成后，点击右上角关闭按钮

打开 main.user.js 并选择全部、复制

点击Edge右下角菜单按钮(同第2步)并点击扩展按钮

在弹出的菜单中选择篡改猴

在弹出的菜单中选择添加新脚本

在脚本编辑器中将你刚才复制的 main.user.js 脚本替换原本的内容粘贴进去

在粘贴完成之后，点击编辑器下的文件按钮，在菜单中选择保存

当显示操作完成后，确认升学E网通助手脚本处于开启状态。

使用Edge打开升学E网通 (https://www.ewt360.com) ，在右下角的菜单中选择查看桌面网站

在Edge中登录自己的账号，即可正常看课，至此为止，手机端教程结束

支持油猴脚本扩展的手机浏览器除了Edge还有via、chrome、X浏览器、Firefox等等

😘手机端使用tip:

不要使用你自带的手机浏览器或者类似于百度、UC、夸克之类的浏览器.

如果你手机里有via浏览器，可以直接使用via中的脚本功能(不支持更新)

若你想要使用此脚本，请用你启用了脚本的浏览器看升学e网通的视频！请不要用下载的升学e网通app

升学e网通官网使用时请点击访问网页版或使用菜单中的“查看桌面网站”

请注意： 在 锁定进度条 功能关闭情况下调整进度条会影响课程的完成度
