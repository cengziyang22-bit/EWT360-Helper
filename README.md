# ⭐ 一键安装（电脑 / 手机通用）

**先装好油猴（Tampermonkey），然后手机或电脑打开下面这个链接，点击"安装"即可，不需要复制粘贴任何代码：**

### 📱 [点这里一键安装 3.4.1](https://www.tampermonkey.net/script_installation.php#url=https://github.com/cengziyang22-bit/EWT360-Helper/raw/refs/heads/main/main.user.js)

安装成功后打开升学E网通（请使用"查看桌面网站"），登录即可使用。脚本会自动更新到最新版。

# 💖使用教程 - PC端(此处以Edge作为演示)
1. 在Edge的插件商店在下载安装油猴(篡改猴)[Tampermonkey](https://microsoftedge.microsoft.com/addons/detail/%E7%AF%A1%E6%94%B9%E7%8C%B4/iikmkjmpaadaobahmlepeloendndfphd)
2. 打开上面的一键安装链接（或直接访问 [Script Installation | Tampermonkey](https://www.tampermonkey.net/script_installation.php#url=https://github.com/cengziyang22-bit/EWT360-Helper/raw/refs/heads/main/main.user.js)）
3. 在Edge的管理插件页面中打开开发人员模式
5. 在Edge的油猴插件管理界面中打开**允许用户脚本**
6. 至此为止，PC端教程结束，你可以关闭没用的窗口，然后使用浏览器播放网课试试
- **请注意：** 在 *锁定进度条* 功能关闭情况下调整进度条会影响课程的完成度

# 💖使用教程 – 手机端(以Firefox安卓版为演示，最省事)

手机端请用**Firefox(火狐)安卓版**或 **Kiwi浏览器**，不要用自带浏览器 / 百度 / UC / 夸克。

**Firefox 安卓版：**
1. 在应用商店搜索安装 **Firefox**（火狐浏览器）
2. 打开 Firefox → 菜单 → 附加组件 → 搜索并安装 **Tampermonkey（篡改猴）**
3. 在地址栏打开升学E网通 (https://www.ewt360.com) ，点右下角菜单 → **查看桌面网站**
4. 在浏览器中打开上面的**一键安装链接**，点击"安装"按钮
5. 完成后重新打开升学E网通，登录账号即可正常看课
- **注意**：若提示安装的脚本不生效，请确认 Tampermonkey 已启用，并已对网页开启脚本注入

**Kiwi 浏览器（Chrome 内核，可装电脑端油猴）：**
1. 应用商店搜索安装 **Kiwi Browser**
2. 打开 Kiwi → 菜单 → 扩展程序 → 开启**开发者模式** → 打开 [Tampermonkey](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) 的Chrome商店页面安装
3. 在 Tampermonkey 设置中开启**允许用户脚本**
4. 打开**一键安装链接** → 安装
5. 打开升学E网通 → 查看桌面网站 → 登录使用

**Edge 手机版（步骤多，不推荐）：**
1. 手机安装 Edge，打开 → 右下角菜单 → 扩展 → 找到篡改猴 → 获取（需开启开发者模式）
2. 打开**一键安装链接** → 点击安装
3. 打开升学E网通 → 查看桌面网站 → 登录使用

# 😘手机端使用tip:
- 不要使用你自带的手机浏览器或者类似于百度、UC、夸克之类的浏览器.
